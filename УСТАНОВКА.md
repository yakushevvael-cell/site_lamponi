# Установка на собственный сервер

Приложение переведено с Cloudflare Workers на обычный сервер: Node.js, база в
файле SQLite, файлы ОСВ на диске, nginx с сертификатом, синхронизация по
расписанию через systemd.

## Что нужно

- Сервер Ubuntu с root-доступом. Проверено на конфигурации 2 CPU / 2 ГБ RAM /
  30 ГБ. Меньше 2 ГБ памяти брать не стоит: сборка не помещается.
- Домен, указывающий на IP сервера (A-запись).
- Архив с исходниками (`lamponi-node.tar.gz`) либо адрес git-репозитория.

## Установка

Скопируйте архив на сервер и запустите скрипт от root:

```bash
scp lamponi-node.tar.gz root@СЕРВЕР:/root/
ssh root@СЕРВЕР
tar -xzf lamponi-node.tar.gz -C /root/lamponi-src --one-top-level
DOMAIN=fbs.lamponi.store ADMIN_EMAIL=ваша@почта \
  SOURCE_ARCHIVE=/root/lamponi-node.tar.gz \
  bash /root/lamponi-src/deploy/install.sh
```

Скрипт ставит Node 24, nginx и certbot, заводит системного пользователя
`lamponi`, генерирует секреты, собирает приложение, поднимает сервис и таймеры.
Занимает 10–15 минут, повторный запуск безопасен.

`ADMIN_EMAIL` нужен только для выпуска сертификата Let's Encrypt. Если домен
ещё не указывает на сервер, оставьте его пустым и выпустите сертификат позже:
`certbot --nginx -d fbs.lamponi.store`.

## Первый вход

Откройте `https://fbs.lamponi.store/register`. **Первый зарегистрировавшийся
становится администратором** — сделайте это сразу после установки, пока адрес
никто не знает. Остальные сотрудники регистрируются сами и ждут, пока вы
подтвердите доступ на вкладке «Пользователи».

Дальше по порядку:

1. «Подключения» — добавьте API-ключи Wildberries и Ozon. Ключи с прежнего
   хостинга не переносятся: они были зашифрованы другим серверным ключом.
2. «Склады» — «Обновить список складов», затем включите выгрузку только на
   нужном действующем складе.
3. «Загрузка ОСВ» — загрузите свежую ОСВ, указав её дату. После применения
   синхронизация запустится сама.

## Где что лежит

| Путь | Что это |
| --- | --- |
| `/opt/lamponi/current` | код приложения |
| `/opt/lamponi/shared/.env` | настройки и секреты, при обновлении не трогаются |
| `/var/lib/lamponi/lamponi.db` | база |
| `/var/lib/lamponi/storage` | загруженные файлы ОСВ |
| `/var/lib/lamponi/backups` | копии базы, хранятся 14 дней |

## Расписание

| Задача | Когда | Что делает |
| --- | --- | --- |
| `lamponi-sync-orders.timer` | каждые 30 минут | загружает заказы, пересчитывает резервы |
| `lamponi-sync-stocks.timer` | каждый час в :10 | выгружает остатки на площадки |
| `lamponi-backup.timer` | ежедневно в 3:30 | копия базы |

Порядок не случаен: остатки уезжают через 10 минут после обновления заказов,
чтобы резерв был свежим. Фоновая выгрузка **никогда** не подтверждает массовое
обнуление сама — если расчёт даёт ноль больше чем по половине позиций, задача
останавливается с ошибкой, а решение принимает человек.

## Полезные команды

```bash
systemctl status lamponi                 # состояние сайта
journalctl -u lamponi -n 100 --no-pager  # журнал приложения
journalctl -u lamponi-sync-stocks -n 50  # журнал последней выгрузки остатков
systemctl list-timers 'lamponi*'         # когда сработают таймеры

systemctl start lamponi-sync-stocks      # выгрузить остатки прямо сейчас
node /opt/lamponi/current/scripts/backup.mjs   # копия базы вручную
```

## Обновление

```bash
bash /opt/lamponi/current/deploy/update.sh
```

Скрипт останавливает таймеры, делает копию базы, забирает новый код, собирает
его и перезапускает сервис. Если сборка не удалась, возвращается предыдущая
версия и таймеры включаются обратно — сайт не остаётся лежать.

Работает только если код ставился из git-репозитория. При установке из архива
обновление делается повторным запуском `install.sh` с новым архивом.

## Восстановление из копии

```bash
systemctl stop lamponi lamponi-sync-orders.timer lamponi-sync-stocks.timer
cp /var/lib/lamponi/backups/lamponi-ГГГГ-ММ-ДД...db /var/lib/lamponi/lamponi.db
chown lamponi:lamponi /var/lib/lamponi/lamponi.db
systemctl start lamponi lamponi-sync-orders.timer lamponi-sync-stocks.timer
```

## Важное про секреты

`CREDENTIALS_MASTER_KEY` в `/opt/lamponi/shared/.env` — ключ, которым зашифрованы
API-ключи маркетплейсов в базе. При его потере расшифровать их нельзя, ключи
придётся добавить заново. Файл `.env` не попадает ни в архив, ни в репозиторий.
Сохраните его копию отдельно, вместе с копиями базы.
