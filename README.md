# Lamponi FBS Hub

Управление остатками FBS и синхронизация с Wildberries и Ozon.

Из ОСВ 1С считается доступный остаток, из заказов площадок — резерв, и результат
выгружается на выбранные администратором склады маркетплейсов.

## Как это работает

```
available = clamp(0, ОСВ − активный резерв − страховой запас, ОСВ)

Wildberries: amount = available
Ozon:        stock  = min(available + min(наш_резерв, reserved_ozon), ОСВ)
```

Перед каждым запросом к площадке значение проходит проверку
`0 ≤ отправляемое ≤ ОСВ`. Не прошло — запрос не уходит, синхронизация встаёт,
строка с числами пишется в журнал. Вся арифметика живёт в одном месте,
`lib/stock-math.mjs`, и её используют и экран остатков, и выгрузка.

## Устройство

| Папка | Что внутри |
| --- | --- |
| `app/` | страницы и HTTP-API (Next.js App Router) |
| `components/` | интерфейс |
| `lib/` | расчёт остатков, резервы, клиенты WB и Ozon, разбор ОСВ, сессии |
| `db/`, `drizzle/` | схема и миграции SQLite |
| `scripts/` | фоновая синхронизация и резервные копии |
| `deploy/` | установка на сервер, systemd, nginx |
| `tests/` | юнит-тесты формулы, повторов и разбора ОСВ |

## Разработка

```bash
npm install
npm run dev     # http://localhost:3000
npm test        # юнит-тесты
npm run build   # сборка
```

База создаётся сама при первом запуске в `./data`, миграции применяются
автоматически. Для работы с площадками нужен `.env` — образец в `.env.example`.
